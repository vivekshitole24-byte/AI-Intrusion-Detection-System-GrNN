Why Granulation Changes Everything

❌ Traditional AI / ML Model

  • Inspects each packet row in complete isolation with no temporal memory
  • Treats all 78 features at a single, uniform scale
  • Completely misses slow brute-force attempts spread over hours
  • Cannot distinguish which feature level triggered the alert
  • Drowns rare attack classes in majority-class noise (class imbalance)
  • Runs heavy full inference on every single packet

✅ Granular Neural Network (GrNN)

  • Processes traffic at micro, meso, and macro scale simultaneously
  • Splits 78 features into 3 semantically meaningful granule groups
  • Macro granule catches stealth attacks across hours of history
  • Reports exactly which granule flagged the threat with alpha weights
  • Class-weighted granular attention isolates rare attack patterns
  • Micro-subnet acts as fast pre-filter, reducing compute by up to 70%

Simple Example: Catching a Stealthy Brute Force

Traditional AI sees each row alone:

  • 8:00 AM — 1 login attempt, 64 bytes, 0.02s → "Normal"
  • 8:30 AM — 1 login attempt, 64 bytes, 0.02s → "Normal"
  • 9:00 AM — 1 login attempt, 64 bytes, 0.02s → "Normal"
  • ... repeats 48 times over 24 hours → ALL marked "Normal"
  • Attacker guesses password by midnight. Zero alerts raised.

GrNN Macro Granule groups 4 hours of timing data:

  • Micro Granule: Each packet looks clean (normal flags, normal size)
  • Meso Granule: Each flow session is short and clean
  • Macro Granule: "Same IP failed auth 8 times at exact 30-min intervals across 4 hours"
  • Dominant: Macro (72%) → Stealth Brute Force detected
  • Alert raised with full granule attribution breakdown
